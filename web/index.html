Un LLM escribe.Jev decide.Juntos, cada uno a lo suyo.

El mismo ticket de soporte recorre tres caminos en vivo contra OpenRouter. El LLM tiene que redactar un JSON y luego hay que leerlo. Jev, un modelo de decisión, devuelve directamente probabilidades. El flujo combinado deja decidir a Jev y solo llama al LLM cuando hay algo que escribir.
